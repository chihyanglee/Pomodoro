# Pomodoro

A simple focus timer with a fullscreen countdown. No build step, no dependencies — just static HTML, CSS and JS.

**Live:** https://chihyanglee.github.io/Pomodoro/

## Features

- Focus / break durations with quick presets
- Four color themes: Clean, Midnight, Falling Colors, Grayscale
- Three timer styles: Digital, Ring, and Bar (an LCD bar timer)
- Fullscreen countdown, screen wake lock, chime when time is up
- Keyboard: `Space` pause · `R` restart · `F` fullscreen · `Esc` exit

## Run locally

```sh
python3 -m http.server
```

Then open http://localhost:8000.
